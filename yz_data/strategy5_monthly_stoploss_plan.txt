OVERVIEW
--------
This plan outlines the implementation of a sophisticated stop loss strategy
that tracks positions month-by-month throughout the holding period, closing
positions when they hit the 50% stop loss threshold and optionally reinvesting
capital.

CURRENT LIMITATION
------------------
The existing dataset (signals_with_returns_and_tickers_{year}.parquet) contains:
- Annual returns only (ret column = 12-month return)
- Form date (form_date) - when the portfolio is formed
- No intra-year price or return tracking

REQUIRED DATA
-------------
To implement monthly stop loss tracking, you need:

1. Monthly Stock Returns from CRSP
   - Data source: CRSP Monthly Stock File
   - Required fields:
     * permno (stock identifier)
     * date (monthly date)
     * ret (monthly return)
     * prc (monthly price - optional but helpful)
     * vol (monthly volume - optional for liquidity checks)

2. Risk-Free Rate (Monthly)
   - Fama-French monthly risk-free rate
   - Or use existing annual rf divided by 12 (approximation)

3. Merge Logic
   - Match by: permno
   - Time window: 12 months following form_date for each stock
   - Example: If form_date = 2010-06-30, track returns from July 2010 to June 2011

2.1 Position-Level Tracking Function

def track_position_with_stoploss(monthly_returns, stop_loss_pct=0.50,
                                  reinvest=False):
    """
    Track a single position month-by-month and apply stop loss.

    Parameters:
    -----------
    monthly_returns : array-like
        Monthly returns for the position (12 months)
    stop_loss_pct : float
        Stop loss threshold (0.50 = 50% loss)
    reinvest : bool
        If True, reinvest stopped-out capital

    Returns:
    --------
    dict with:
        - final_return: realized return after stop loss
        - stopped_out: True if stopped out
        - stop_month: month when stopped (or None)
        - months_held: number of months position was held
    """
    cumulative_return = 0.0
    position_active = True
    stop_month = None

    for month_idx, monthly_ret in enumerate(monthly_returns, 1):
        if not position_active:
            break

        # Update cumulative return
        cumulative_return = (1 + cumulative_return) * (1 + monthly_ret) - 1

        # Check stop loss (for short positions, flip the sign)
        # For short: we lose money when stock goes up
        # Stop loss triggers when loss exceeds threshold
        if cumulative_return < -stop_loss_pct:
            stop_month = month_idx
            position_active = False
            cumulative_return = -stop_loss_pct  # Cap at stop loss
            break

    return {
        'final_return': cumulative_return,
        'stopped_out': stop_month is not None,
        'stop_month': stop_month,
        'months_held': stop_month if stop_month else 12
    }

2.2 Portfolio-Level Tracking

For each year:
    1. Select long portfolio (top 10%)
    2. Select short portfolio (bottom 100)

    For long positions:
        - Track normally (optional: apply stop loss here too)
        - Calculate return: sum of individual stock returns

    For short positions:
        - For each stock:
            a) Get 12 monthly returns
            b) Flip sign (short position: -ret)
            c) Apply track_position_with_stoploss()
            d) Record: final_return, stopped_out, stop_month
        - Aggregate:
            * Average return across all shorts
            * Count stopped positions
            * Average holding period

2.3 Capital Reallocation (Optional Enhancement)

    Option A: Cash Position
        - When position stops out, hold cash (0% return)
        - Simplest approach

    Option B: Reinvest in Remaining Positions
        - When position stops out, distribute capital to active positions
        - More realistic but complex

    Option C: Reinvest in New Stocks
        - Maintain replacement pool (next worst stocks)
        - Most realistic but most complex
